# DEVCHAT 🧑‍💻💬

A real-time chat application built specifically for developers to connect, collaborate, and communicate effectively.

## 🚀 Features

- 🔐 User Authentication (login/signup)
- 💬 Real-time chat with WebSocket support
- 👥 Multi-user chatrooms
- 📄 Markdown support for code sharing
- 🌙 Developer-friendly UI with dark mode

## 🛠️ Tech Stack

- **Backend:** FastAPI
- **Frontend:** React /
- **Database:** PostgreSQL / SQLite
- **WebSocket:** FastAPI WebSocket
- **ORM:** SQLAlchemy
- **Validation:** Pydantic
